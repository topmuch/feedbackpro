## Context

The Audit Matin tab (`/dashboard/audit-matin`) is a daily checklist feature
generated by the Coach IA. The previous UI was functional but visually flat.
The Pro Dashboard is now also used by airport sector Pros (typeEtablissement
=== "Aéroport"), and the audit matin needed to surface airport-specific
signalement metrics in addition to the standard checklist.

## What changed

### API route (`/api/pro/audit-matin/route.ts`)

1. **New helper `calculerAirportStats()`**: queries the database for all
   `AirportReport` rows from the last 24h, then computes:
   - `total24h`, `enAttente`, `enCours`, `resolus` (global counts)
   - `byZone`: for each of the 5 canonical zones (`bagages`, `sanitaires`,
     `files_attente`, `embarquement`, `restauration`) — count + enAttente
   - `slaCompliance`: average % of resolved reports within their zone's
     `AirportSla.targetMinutes`. Zones without a target or without resolved
     reports are excluded; if no zone qualifies, returns 100 by default.
   - The 5 canonical zones are sourced from `AIRPORT_ZONES` in
     `@/lib/airport-config` so the order/naming/emoji stays in sync with
     the rest of the airport feature.
   - The helper never throws — on DB error it returns zeros.

2. **GET endpoint**: detects `ctx.pro.typeEtablissement === "Aéroport"`
   and, when true, computes `airportStats` in parallel with the existing
   audit lookup. The field is attached to the response in both branches
   (audit already completed AND checklist generated) using spread:
   `...(airportStats ? { airportStats } : {})`.
   For non-airport Pros, the field is absent — the existing contract
   for non-airport Pros is unchanged.

3. **Types exported**: `AirportStats` and `AirportZoneStat` so the
   frontend can mirror the exact shape.

4. `ok` / `fail` envelope from `@/lib/session` preserved. POST endpoint
   is untouched.

### Component (`audit-matin-tab.tsx`)

Full redesign with the following premium UI improvements:

1. **Premium sunrise header**: gradient cards (`from-amber-50 via-orange-50
   to-rose-50`), large sunrise icon in a rounded-3xl badge, dynamic
   `salutation()` (Bonjour / Bon après-midi / Bonsoir), full long date.

2. **Circular score gauge** (`ScoreGauge` component, pure SVG): used in
   the "done" view to show the day's score as a colored ring + big
   percentage in the center, and in the "checklist" view as a live
   progression indicator. Colors: green (≥80%), amber (≥60%), red (<60%).

3. **Items grouped by urgency** with section headers:
   - "Priorités hautes" (rose, AlertTriangle icon)
   - "Points de vigilance" (amber, Activity icon)
   - "Vérifications de routine" (emerald, Check icon)
   Each section shows the count as a Badge and has a colored left border.

4. **Photo thumbnails** (`PhotoThumb` component): inline clickable 48px
   thumbnails that open the full photo in a new tab, with hover overlay.

5. **Larger touch targets**: validation buttons now `h-10 px-4` (was
   `h-9`), primary CTA `h-11 px-6`, with hover shadow effects.

6. **Better spacing**: `space-y-5/6`, larger padding (`p-6 sm:p-8`),
   consistent rounded corners (`rounded-2xl`/`rounded-3xl`).

7. **New `AirportSection` component** (visible only if
   `session?.pro?.typeEtablissement === "Aéroport"`):
   - Premium emerald gradient card with Plane icon
   - 4 KPI cards: En attente / En cours / Résolus / Conformité SLA
   - Grid of 5 zone cards (canonical order from `AIRPORT_ZONES`)
     with zone emoji, count, and "X en attente" indicator
     (amber highlight when enAttente > 0)
   - Displayed in 3 views: idle (preview before starting audit),
     checklist (during audit), and done (recap after completion)

8. **`useAppStore` integration**: reads `session.pro.typeEtablissement`
   to compute `isAeroport` flag. Airport section is conditionally
   rendered only when both `isAeroport` AND `airportStats` are truthy.

9. **VueHistorique** sub-component lightly restyled: uses the new
   `PremiumHeader` component for consistency, line-clamp fix.
